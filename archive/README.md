# Archive of earlier submission versions

This folder keeps earlier versions of the FlowMOP manuscript and of the responses to the reviewers. The current documents are in the repository root.

- `2026-10-06_major_revision/`: the major-revision submission of 6 October 2026.
  - `*_06102026.pdf` and `*_06102026.docx`: the submitted manuscript, the tracked manuscript and the point-by-point response, in PDF and Word.
  - `reviewer_response_point_by_point*.md`, `.tex` and `.pdf`: the source and the build of that response.
- `*/local/`: local drafts, planning notes and annotated copies. Git does not track these folders (see `.gitignore`).
  - `2026-05_original/local/`: the original May 2026 Word manuscript and its Markdown conversion.
  - `2026-10-06_major_revision/local/`: the revision plan, the comment matrix, the round-2 notes and the annotated response.
