# Wiley LaTeX template files

The files in this directory are taken from Wiley's official `WileyDesign.zip`
authoring-template package:

- Source: <https://authors.wiley.com/asset/WileyDesign.zip>
- Downloaded: 3 August 2026
- SHA-256: `afda236027a0d02837e720014f4fee60e58e25c0595927842beb53c1df75fd98`

`USG.cls`, its bundled support styles, bibliography files, image assets, and
STIX font files are retained verbatim. The package's uppercase `LETTERSP.STY`
is stored as `lettersp.sty` for compatibility with case-sensitive systems;
its contents are unchanged. The FlowMOP-specific manuscript wrapper is
maintained separately in `../flowmop-template.tex`.
